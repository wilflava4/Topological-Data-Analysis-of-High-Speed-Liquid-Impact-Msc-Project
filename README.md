# Topological-Data-Analysis-of-High-Speed-Liquid-Impact-Msc-Project

The files in this repository are an accompaniment to the provided dissertation. Included in the code files are `Peashooter_mk2.py` which was a mini simulator created to test the droplet statistic analysers before tackling the larger datasets. Originally there was potential for the simulations to have split information about how much volume of each liquid was present in each droplet. This didn't come to fruition in the final product but the code to handle this was kept, this is what vol_1 and vol_2 represent. The code to get statistics for the ejected droplets are found in `Droplet_Stats.py`, this code assumes that the data is presented in the form of Pandas DataFrames. These DataFrames should consist of columns labelled 'time', 'droplet_ID', 'vol_t', 'x', 'y', 'z', 'v_x', 'v_y' and 'v_z'. The DataFrames should also have row indices reset such that the nth line has index n-1. The final code file, `Interface_Analyser.py`, contains the code developed to analyse the 3D point clouds of the interfaces between the air and water from simulations. All code here assumes that the point clouds come in the form of Pandas DataFrames with the columns 'x', 'y', 'z', and 'angle' where the angle is calculated via np.atan2(z,x). The code assumes that gravity acts in the y-direction and that the splash is centred at x=z=0. Many of the functions are duplicated, for example `find_roots()` and `find_roots2()`, the two functions represent the two different simulation types, when there is no number this is code for the droplet on a pool when there is it is for two droplets colliding. This is somewhat clunky but was done to prevent painstakingly editing every single function to have multiple test cases late on in the project. This code also calls on another python file named `ReadFiles.py` which has not been included in this repository. This was simply a separate script used to convert datasets stored on my personal laptop in the form of .dat files into the DataFrame format shown above.

The code was made for personal use rather than to be released as a splash analysis code package, readers of the dissertation may find it useful to have a deeper look at some of the specifics of what was done to analyse the splashes. Researchers doing future projects may also wish to look through some of this work to see what was done and potentially use some ideas, though it is likely that many efficiency improvements could be made throughout the code in order to improve runtimes!

Also included is a pdf of the dissertation itself as well as some animations. These animations help to better visualise the splashing processes and how features evolve over time. The animations included are the droplets from the mini simulator, a top view of the evolution of the jet roots over time, and the evolution of the centre line from one slice over time. Each frame of the centre line animation has 2 orange dots at the base of the jet which are the roots and 2 red dots which are halfway up each jet, these red dots show how the same number of points up along each side of the jet may not be directly opposite each other.
